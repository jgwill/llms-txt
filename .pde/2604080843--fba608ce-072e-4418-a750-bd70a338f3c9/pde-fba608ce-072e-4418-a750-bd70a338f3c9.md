# Prompt Decomposition

> Engine: **copilot** (gpt-5-mini)

## Four Directions

### 🌅 EAST — Vision

- Goal: Make README.md point readers to the docs/ directory (clear, relative link) [90%]
- Decide whether link should be './docs/', 'docs/', or a URL (clarify if needed) [70%] _(implicit)_

### 🔥 SOUTH — Analysis

- Locate all documentation links in README.md and identify current targets [90%]
- Check that docs/ contains an index or landing page to link to [80%] _(implicit)_

### 🌊 WEST — Validation

- Verify updated links resolve locally and in GitHub rendering (open docs/index.md or run link check) [85%]
- Review README visually to ensure wording still reads well after link change [80%]

### ❄️ NORTH — Action

- Edit README.md to replace doc paths with docs/ (commit change) [95%]
- Push commit and optionally open a PR for review [60%] _(implicit)_

## Original Prompt

> Update the README.md to point to the docs/ directory

## Primary Intent

**Action:** update
**Target:** README.md (documentation links) to point to docs/ directory
**Urgency:** immediate
**Confidence:** 95%

## Secondary Intents

1. **search** — README.md for existing documentation links/paths _(explicit)_
2. **verify** — docs/ directory exists and contains an entry (index/README) to link to _(implicit)_
   - depends on: search
3. **replace** — link(s) in README.md so they point to docs/ (use relative path) _(explicit)_
   - depends on: verify
4. **update** — any other references (badges, TOC) that point to old doc location _(implicit)_
   - depends on: replace
5. **validate** — that updated links resolve locally (e.g., open docs/index.md or run simple link check) _(explicit)_
   - depends on: replace
6. **commit** — git commit README.md change _(explicit)_
   - depends on: replace
7. **push_or_pr** — push branch and/or create PR with the change _(implicit)_
   - depends on: commit

## Ambiguity Flags

- **"Which exact link(s) in README.md should be changed (one or multiple references)?"**
  - Suggestion: Provide the line or current link text/URL to update, or confirm 'all doc-related links' should point to docs/
- **"Should links use 'docs/', './docs/', or a full URL?"**
  - Suggestion: Specify preferred link format (relative vs absolute) or confirm default to 'docs/'
- **"Commit workflow: commit directly to main or create a branch and PR?"**
  - Suggestion: State preferred workflow (commit to main, or create branch named like 'fix/readme-docs-link' and open PR)
