## Platform Overview

The Medicine Wheel Developer Suite is a layered npm package ecosystem grounded in **Two-Eyed Seeing**. It bridges the Engineer-world's precision with the Ceremony-world's relational accountability. `ontology-core` serves as the platform nucleus, defining the fundamental beings (Nodes, Relations, Ceremonies) that all other packages interact with.

---

## 1. Foundational Layer
*The soil and the roots.*

### medicine-wheel-ontology-core
> Platform nucleus: TypeScript types, RDF vocabulary, Zod schemas, Wilson alignment scoring, and OCAP tracking. Relationships are first-class beings with ceremony context and obligations.
- **npm**: https://www.npmjs.com/package/medicine-wheel-ontology-core
- **Role**: Foundational source of truth for all types and constants.
- **Key types**: `RelationalNode`, `Relation`, `Direction`, `OCAPFlags`, `WilsonAlignment`, `AccountabilityTracking`.

### medicine-wheel-data-store
> Shared Redis persistence layer: Provides unified access to relational memory (Nodes, Edges, Ceremonies) and bidirectional session-ceremony linking.
- **npm**: https://www.npmjs.com/package/medicine-wheel-data-store
- **Role**: Relational memory storage and access.

## Alignment Principles

- **Relational Accountability**: Every package serves to strengthen the web of relations between researcher, community, land, and spirit.
- **Circular Progression**: Work is not linear but spiral; revisiting a topic (circle depth) is a sacred act of deepening understanding.
- **OCAP® Sovereignty**: Indigenous data sovereignty (Ownership, Control, Access, Possession) is enforced at the code level.
- **Wilson Validity**: Research is validated by its transformative impact on all participants and the health of the resulting relations.
