## Key Findings

### The Miadi Platform Gap

The current LLMS-txt provides foundational frameworks (structural tension, creative orientation, relational research) but **lacks operational guidance** on how these frameworks are implemented in actual Miadi kit deployments. This upgrade closes that gap with 4 new documents:

1. **Orchestration Handoff Contracts & State Management** — How agents coordinate through markdown state
2. **Miadi Plugin Architecture** — Plugin-first deployment model for kits
3. **Medicine Wheel Relational Foundations** — Consent-aware, ceremony-aware orchestration
4. **MCP Transparent Integration** — Distributed tool abstraction for multi-agent orchestration

### Why These Matter

- **Operational Readiness**: Enables engineers to deploy and extend Miadi kits without reverse-engineering practice patterns
- **Relational Preservation**: Ensures Medicine Wheel and consent-aware stewardship are preserved across kit implementations
- **Ceremonial Intent**: Supports non-technical users (writers, storytellers, ceremony keepers) in evaluating and using kits with confidence
- **Ecosystem Coherence**: Closes the bridge between theoretical frameworks (LLMS-txt) and practical orchestration (Miadi kits)

## Context & Background

The Miadi Orchestration Kit is a family of specialized Copilot plugins designed to coordinate complex creative and technical workflows. Its architecture is grounded in:

- **Robert Fritz's Structural Dynamics** (tension-driven creation, not problem-solving)
- **Medicine Wheel Paradigm** (relational, ceremonial, community-aware)
- **Deep Research Foundations** (source ledgers, provenance, ceremony state)
- **Narrative Stewardship** (agents as responsible keepers, not neutral tools)

This LLMS-txt guidance set ensures those principles are visible, teachable, and reproducible across deployments.
